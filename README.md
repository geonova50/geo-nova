# GEO NOVA — Geoinformatics Learning Platform

A modern responsive React + Tailwind CSS landing/portal UI for GEO NOVA, based in Chennai, India.

## Stack

- React + Vite
- Tailwind CSS
- Framer Motion
- Lucide React icons
- Inline SVG map/globe visualizations

## Included

- Responsive sticky navigation with mobile menu
- Animated hero spatial/globe visualization
- Framer Motion scroll reveals and hover micro-interactions
- Animated counters
- About / learning approach section
- Interactive software training cards: QGIS, Google Earth Engine, SNAP, Python Automation
- Surveying instrument cards: Total Station and DGPS
- Bento-style platform capabilities
- Chennai location block with styled vector map
- Contact inquiry form with demo success state
- Login modal demo
- Footer with Chennai, India location

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Production integration notes

The forms and Login modal are intentionally frontend/demo interactions. Connect them to your preferred backend/auth service, CMS/video storage, webinar provider, subscription/payment provider, and email/CRM workflow before production.
